# 同帧率光影细节优化验收

2026-10-05。基线是本次工作开始时的 r186 工作区副本（`artifacts/quality-20261005-baseline/public`），包含上一轮高清输出、MSAA 与运动插值；本轮比较不混入 r185 → r186 的引擎差异。

## 实现与边界

- 均衡/精细档增加接触环境遮蔽：复用主场景深度，半场景分辨率、固定八方向采样；只增加一次屏幕绘制，不再画一遍单位/地形，不累积历史帧。重建法线选择轮廓同侧，按深度进行上采样，减轻黑边。
- 遮蔽先处理场景，泛光随后合成，HUD 仍使用独立清晰输出。流畅档关闭遮蔽并释放深度/AO目标；WebGL/格式不支持时回退。开启 MSAA 时，只有使用遮蔽才 resolve 深度。
- 斜视纹理过滤由原来的 4 提升到设备支持范围内的 8，颜色、法线与粗糙度贴图都按档位配置。精细档阴影贴图从 1024×1024 提高到 2048×2048。
- 复用阴影投影：镜头、地图、画质和迷雾快照立即失效；旋转/移动投影最多 30Hz，主场景仍按显示帧率渲染。新局与时钟回退复位，建筑生成/消失、施工、旋转、后坐与坍塌保持更新。
- 未改变服务器模拟、单位真实位置、战斗/资源/迷雾判定；未添加运行依赖或修改系统性能/安全设置。

## 回归

76 项 Python 离线测试、30 项 JavaScript 回归脚本通过。新增回归执行实际后处理目标和透视相机，检查 MSAA 深度 resolve、AO 半分辨率、清晰输出、相机矩阵变化、关闭/重开资源释放及弱能力回退；在 30/60/144Hz 验证阴影调度、即时失效与换局。

独立本机服务 HTTP/SSE 集成通过，覆盖迷雾、建造、移动、SSE、聊天与视觉资源；验收后停止临时联机服务，渲染预览服务保留供查看。

## 浏览器性能

Intel Arc 130T / ANGLE D3D11 / WebGL2，1280×720 参考渲染尺寸、1920×1080 场景及输出（DPR 1.5），400 部落单位、26 建筑，移动开启、建筑阴影、轻量泛光、粒子 150。浏览器预览会按面板大小缩放显示，不改变参考场景与 GPU 输出尺寸。相同随机种子和固定模拟步长，全部资源/着色器预热后 90 帧预热 + 300 帧采样。

新均衡增加了 AO 与纹理细节，同时保持 400 个完整单位模型和原场景/输出分辨率。平均场景绘制次数减少 16.7%；算上新增 AO 后处理，平均总次数从 224 降到 188.5，减少 15.8%。390 帧（预热+采样）内，阴影重画 195 帧、复用 195 帧。

相邻基线 3 → 新均衡 2 的 GPU 时间仍有增加（9.018 → 10.119ms 中位数），换得更细致的光影；不能把绘制次数下降解释为 GPU 时间同比下降。重复基线显示功耗/频率对计时有显著影响。60FPS 受垂直同步限制，结论是本机保持相同刷新率，不是硬件速度翻倍。

精细档保持相同场景和输出分辨率，使用更强接触遮蔽、4 倍 MSAA、2048 阴影与 8 倍纹理过滤，本机保持 60FPS。16 倍过滤的试配在同负载下出现 57.51FPS / 33.4ms p99，最终取 8 倍过滤，保留更精细投影并减少额外采样开销。

浏览器实时切换验证：关闭遮蔽后变成 0 次 AO 绘制 / 1×1 AO 占位 / 1024 阴影 / 0 MSAA，纹理计数回到 18；从流畅档切回精细档后，恢复 960×540 AO / 2048 阴影 / 4 MSAA，纹理计数 20。地图和 13 个单位未重建，未出现渲染错误。

4 张地图 × 3 档阴影/泛光 × 4 轮，共 48 次换图/档位组合检查完成，未出现渲染错误。最后两轮的每个地图/档位组合，几何、纹理和程序计数完全一致；纹理稳定在 23，河谷高档位几何 264 / 程序 83，未观察到持续增长。

桥头实际画面对照使用相同种子、参考视角、1920×1080 输出、4 倍 MSAA 与固定 18 秒场景。基线截图：`artifacts/river-art-captures/render-92003da7707c4a6e99b40b46ef66f21e.png`；本轮精细档：`artifacts/river-art-captures/render-385a4b18e6b243f2af8c8f0c4f47ab8e.png`。岩缝、履带/墙脚接触与桥梁/树林投影更有层次，未见轮廓黑带或闪烁错误。
