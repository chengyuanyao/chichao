# 2026-09-10 战场反馈验收

保留已有程序化模型、共享表面图与实例合批，增强运动、开火、命中、受损、辨识和声音。
不是换用全套扫描资产或物理履带。轨带通过材质条纹按累计行程滚动，炮管才使用实际运动矩阵。
未修改战斗数值或地图碰撞；可见特效事件增加弹种、开火实体和战损外观元数据。

- 14 项前端专项通过，包含 30 个单位形态、15 类建筑、模型点选、地形输入、材质、资源释放和声音预算。
- 新增专项验证：停止履带、差速转弯、后坐衰减、识别色保护、地形高度、总粒子/烟尘/残骸上限、
  粒子超时释放、视野移出不炸、炮管参与点选、音频优先级/复用/停止清理、服务端隐藏事件隐私。

## 浏览器 A/B 测试

Codex 内置 Chromium，1280×720，DPR 1，Intel Arc Graphics / ANGLE Direct3D11。
铁峡争渡固定种子 90241，400 移动混编单位 + 15 建筑，受控周期性开火/命中；
镜头 x=1000,y=1500,zoom=.82,yaw=.14,pitch=.96。建筑阴影、关闭泛光、自动 LOD、粒子档 150。
每轮预热 90 帧，采样 300 帧，页面可见；基线为提交 0aa752d 的 public 渲染文件快照。
采样次序：旧一 → 新一 → 新二 → 旧二。

| 轮次 | 平均 FPS | 帧间隔 p95 / p99 ms | CPU render p50 / p95 ms |
| --- | ---: | --- | --- |
| 旧一 | 56.75 | 25.0 / 29.2 | 2.6 / 3.9 |
| 新一 | 58.37 | 20.7 / 29.2 | 3.2 / 4.8 |
| 新二 | 58.02 | 23.0 / 25.0 | 2.6 / 3.3 |
| 旧二 | 49.97 | 31.9 / 37.6 | 2.1 / 3.1 |

均为 400 近景模型，未通过减少可见单位或提前换低模获取结果。旧版约 187 个场景绘制调用，
新版约 195–196；新增为共享炮管、识别标记等批次，不是每单位一个 draw call。
新版 CPU 存在额外成本；目前测例未出现平均帧率回退，但样本小且主机负载存在波动，
不能把差异完全归因为某个优化，也不能当作完整联网对局或任何硬件下的帧率保证。
两版使用相同档位数字，但旧版火光/烟尘分别预算，新版改为合计预算，并降低普通命中装饰密度。
此对比衡量整组表现方案，不是保持粒子数量完全相同的单因素实验。

## 功能实测

- WebGL 实际编译通过，无捕获到的 error/warn；声音经用户手势解锁，真实 AudioContext 创建与播放无报错。
  声音音色是程序生成的设计，未把自动测试当成主观听感验收。
- 180 次密集爆炸：档位 150 时捕获总粒子 139、烟尘 30、残骸 28。
- zoom=.25 时 400 远景模型、独立炮管批次 0、特效密度 .28，危险识别保留。
- 同场即时从 150 降到 60 后，捕获总粒子 45、烟尘 0；未重建地图。
- 同一渲染器连续切换三图四轮（12 次）：每张图对应的几何体、贴图及着色器注册数稳定，
  每轮旧粒子与残骸均清空。该实验是有界换图测试，不代表无限时长内存证明。
- 真实客户端连接本地测试服务，创建双人房间并开局：8 个混编单位框选成功，右键移动后保持
  8 个单位选中、正常到达新位置，界面音效接入无报错；浏览器未捕获到 error/warn。
  该房间使用禁用 AI 的操作夹具，不作为实际联网团战性能数据。

复现：运行 `py -3.13 tests/visual_benchmark_server.py`，打开其打印的本机链接。
选择“战场反馈验收”看近景；“大军团压力”配 `moving=1&combat=1` 验证交战开销。
整个页面是独立合成夹具，不创建房间、不发送对局指令，也不是录像。
