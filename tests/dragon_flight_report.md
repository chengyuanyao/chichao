# 巨龙飞翔验收

2026-09-21，基线 `517b320`。只改变渲染，不修改目录数值、服务器寻路/碰撞。

## 实现边界

- 两套近景外观均支持翼根扇动、悬浮起伏、行进前倾与转向侧倾；按单位 ID 分散相位。
- 翼板和发光边一起运动，核球继承身体矩阵，龙息/余焰使用同序变换。
- 复用实例合批，不增加三角面、材质族、灯光和粒子预算。机械外观新增两个全场共享翼批次，不是每台龙新增两次绘制；默认样板外观原本已有两个翼批次。
- 远景不绘制翼关节、不更新细节姿态；静止远景身体复用矩阵。离屏沿用现有剔除。
- 血条位于巡航高度上方，不因悬浮而把全场血条从原有降频更新强制提高到逐帧更新。

## 功能验证

- 浏览器逐帧检查了机械外观不同翼拍姿态，确认翼板位置变化；右键点翼板命中 `秘法巨龙 · u1`。
- 同一渲染器实时切换另一套外观正常，翼根和身体保持连接。
- `dragon_flight_test.mjs` 验证相位、幅度、转向、停止收敛、LOD、炮口变换及优化矩阵等价性。
- `model_picker_test.mjs` 包含真实翼几何在升空、旋转及上下拍极值时的命中检查。
- 原有 Python 离线测试及全部 Node 测试通过；机械龙数值和归属色回归未改变。

## 性能记录与限制

Intel Arc 集显，1280×720、DPR 1，建筑阴影、无泛光、自动 LOD，200 台近景机械龙、15 座建筑；固定模拟步进，每次预热 90 帧、采样 300 帧。
