# 五车争霸·裂谷旷野验收

2026-09-21。本次独立新增 `central_rift`，原版及其他地图保留，不改变单位数值。

## 玩法

- 4000×4000、最多 5 人，中央折叠基地车开局，中央无矿。
- 五向等角发展高台，背靠林岩；五条弯折河谷、五座侧翼桥，河头可从中央绕行。
- 后方主矿 150000×5、交界争夺矿 80000×5，总储量 1150000。
  同类矿共用局部随机偏移后旋转，防止抽到不同距离；主矿略向内调整，避开山边寻路格。
- 无中立守军；大厅无矿标记，对局沿用实时视野资源隐藏。

## 自动及交互验证

- 全量 60 个 Python 离线测试通过，25 个 Node 测试通过。
- 新增专测：40 个资源随机种子、五家一致的 18 个采样建造选址、五条迁移路线、
  天启/秘法基地车/矿车/巨龙合计 20 次过桥、2/4/5 人开局、总部展开、供电建筑建造、AI 迁移展开。
- 真实地图坐标测试 35 个桥面/引桥点：单位高度与点击射线一致；五个总部四角位于平整高台。
- 静态合批回归：河岸索引有效、属性有限、两岸顶点色保留、共享材质、岩石按空间分块。
- 正式客户端本机房间：地图选项可选，简介与尺寸正确，中立守军开关禁用，能进入对局，开局有基地车。
- 同一渲染器连续四轮切换全部四图（16 次）：同图各轮的几何、纹理、迷雾着色器数量一致。
  裂谷图图鉴场景始终为 185 个几何、17 张纹理、18 个迷雾着色器，没有累积。
- 全景通过实际渲染器输出；仅截图副本放宽相机最远距离，不改变正式游戏相机。

## 性能

地图起伏静态烘焙，共用已有实例化单位、地形高度采样、森林分块和纹理。
河岸树木/碎石改为按河段长度预算，避免弯河每个短段重复获得长河的装饰额度。
相邻山体岩石按空间分块合并，同一河段两岸合并并共享材质；几何外观及碰撞不变。

服务器：4 家共 404 单位，120 步密集战斗，同时生成各玩家快照。
