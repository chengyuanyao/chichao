# r186 引擎与图像管线升级验收

2026-10-03，基线为提交 `862e937` 内置的 Three.js r185。候选使用官方 npm three 0.186.0，下载校验 SHA-512 后由一次性 esbuild 0.25.12 压缩；保留 MIT 许可。运行只需现有 Python 和浏览器，仍可离线使用。

## 升级内容

- Three.js r186 的 module/core 成对更新。发布来源和最终文件 SHA-256 记录在 public/vendor/THREE_VERSION.json。
- 场景目标支持设备可用的 MSAA 档位，与最终 FXAA 配合。只对场景多重采样，泛光和最终输出不多重采样；不读取的深度不额外 resolve。
- 新增流畅、均衡、精细三档图像清晰度，最高输出像素密度分别为 1、1.5、2。阴影、泛光、粒子选项保持独立。
- 自动降档只缩小场景/泛光目标，最终输出和 HUD 保持清晰，点选继续使用 CSS 坐标。仅切换场景比例时不重新编译着色器。
- 8Hz 位置快照采用 80ms 短缓冲，预测最多 40ms；朝向按实际帧间隔平滑。定身使用权威位置；传送、断流、换局复位。全程只更新客户端显示位置。

## 回归

76 项 Python 离线脚本与 29 项 JavaScript 脚本通过。新增引擎回归覆盖版本/校验值配对、颜色/深度共同支持的 MSAA 格式、动态目标尺寸、HUD 分辨率隔离、30/60/144Hz 运动一致性、定身/断流/传送与时钟复位。

真实 HTTP/SSE 集成通过，检查迷雾、建造、移动、SSE 与视觉资源。在单独本机服务的实际对局里验证了均衡/精细设置保存及即时切换、正常基地画面和回基地操作，未见渲染错误；测试服务已停止。

## 浏览器实测

Intel Arc 130T / ANGLE D3D11 / WebGL2，1280×720 CSS 视口、400 部落单位、26 建筑、移动开启、建筑阴影、轻量泛光、粒子 150、固定模拟步长，预热全部目录/着色器后 90 帧预热 + 300 帧采样。

基线与候选按“基线 → 候选 → 候选 → 基线”比较，相同场景的绘制批次均为 219；均衡档增加抗锯齿后维持 60FPS，p95 未回退。高清档把像素面积提高到 2.25 倍，本机仍保持刷新率。GPU 时间随设备功耗/频率变化；浏览器启用垂直同步，60FPS 表示保持当前刷新率，不代表未限帧的最高速度。

高清输出保持 1920×1080，将场景比例降低到 0.7 后，GPU p95 从 13.460ms 降到 6.348ms；精细档使用 4 倍 MSAA、2560×1440 输出与 0.7 场景比例，仍保持 60FPS。以上为当前机器实测，不保证其他设备达到相同速度。
