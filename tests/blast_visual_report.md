# 爆炸反馈第一轮

后续分类残骸、坍塌、音效和跨地图美术已继续实现；最新范围与验证见 battlefield_finish_report.md。下文保留第一轮历史记录。

实现范围：烟火轮廓/冷却、低空扬尘、不规则焦痕、常规命中去光圈、普通步兵阵亡去燃料火球、
按摧毁对象大小有限缩放。沿用现有实例粒子层与粒子/烟雾上限，不改变服务端伤害或碰撞。
与上一轮建筑选中圈修正同时留在工作区，未丢弃该修改。

四个程序化烟团轮廓烘焙在同一张 256×256 RGBA 数据纹理（基础层 256 KiB，含 mip 约 341 KiB）；
每个烟火片元两次采样，沿生命周期流动/冷却。不是流体模拟、摄影火焰序列或完整 3A 资产包。
魔法能量保留原有色相和必要的能量环；放置预览不受影响。

18 个前端测试文件与 Python 展示约束通过。覆盖纹理确定性/边缘留白/细节、固定采样预算、
去光圈、普通步兵死亡、随机寿命从零年龄开始、粒子烟雾残骸数量上限与回收。

本机浏览器（Intel Arc，ANGLE D3D11）实际 shader 无捕获到的 error/warn。
8 次爆炸预热检查：程序数 160 → 160，首帧 CPU 19 ms，后续七帧 1.4–2.0 ms；
该次在最后的体型缩放/生命周期微调前采样，不冒充最终逐字节版本。
最终 1280×720、400 个近景移动单位、15 建筑、合成命中、建筑阴影、无泛光：
90 帧预热 + 300 帧采样，58.63 FPS，frame p95/p99 16.8 ms，CPU p50/p95 5.0/6.3 ms。
203 场景绘制调用；采样结束粒子 91/150、烟雾 21/42。
单轮合成测试不能证明全硬件/完整网络团战零回退，也没有将平均帧率四舍五入宣称恒定 60。

实际渲染截图：`artifacts/river-art-captures/render-84846223025d4cbf92d6143020e7f186.png`。
三个爆炸为测试页主动触发，不是真实对局战果。截图已目视检查。

尚未实现后续阶段：分类车壳残骸、建筑坍塌、授权录制音效、核心模型重制。
目前残骸仍是旧共用几何体；烟火仍是有限的贴片效果，未宣称达到 3A。
