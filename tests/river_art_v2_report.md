# 桥头美术第二轮

基线是本轮开始时的上一版完整 public 快照，位于本机
`artifacts/river-art-v1-snapshot/public`。不是拿早期低画质版本作为基线。

## 实际改动

- 样板的手写固有色作近似 sRGB → 线性解码；已由 THREE.Color 解码的玩家颜色不重复转换，
  大于 1 的发光色仍保持 HDR。暗色橡胶/涂装不再套用裸金属的高金属度。
- 材质按模型局部尺寸投射，替代每个小零件独立铺满整张贴图；法线切线基与投射坐标一致，
  增加接地泥尘。没有增加贴图下载或实时反射。
- 两座总部改为完整新主体，取代上一轮旧主体加装饰。钢铁总部包含肋架机库、卷帘门、
  观察层和通信塔；秘法总部包含石砌塔身、门拱、扶壁及分肋铜色穹顶。
- 人物收窄躯干、缩小头部、保留肩颈与双腿分离；步兵穿深色制服，队色集中到背心，
  不再将整个躯干表现成光滑红色椭球。
- 两种履带天启重做斜甲车体、双炮塔、发动机格栅及排管，人形态更新胸甲和液压结构。
  保留人形态头部/下肢、肩轴与旧远景轮廓，不声称每个零件都重新雕刻。
- 近景复查后，装甲采用硬表面法线和较窄倒角，不将整片钢板平滑成鼓胀曲面。
- 未选中老兵的样板军衔环改为较淡的细线；选中反馈及其他地图的原有显示不变。
- 巨龙抬颈拱翼，加入眼窝、颚、牙齿；同步调整样板专用开火特效高度。
- 翼膜改为深色皮膜、蓝色承力骨架、尖翼端与弧形后缘；骨架和皮膜共用轮廓采样，
  不增加三角形或关节批次。
- 天启双臂使用与主体相同的样板材质与阴影设置，避免躯干与手臂表现不一致。

## 不变的边界

仅 `iron_river_duel` 默认启用样板。地图碰撞、兵种数值、模型缩放、命令和服务器协议不变。
远景仍用旧低模。部件合并/按兵种实例化，新增结构不是每零件一个绘制调用。
两座总部主体分别 4,608 / 4,448 三角形；近景单位与关节合计均低于 3,600 三角形
（天启独立手臂沿用既有批次，未计入主体数字）。

## 验证

15 项前端专项通过，包含新模型缓存、有限顶点/UV、拾取、材质注入、地形输入、画质切换；
Python 展示约束回归通过。本轮没有修改游戏逻辑，上一轮全套逻辑测试结果不冒充本轮重跑。
浏览器实际 WebGL 编译无捕获到的 error。

本轮为实际游戏渲染器中的模型/材质升级，不是完整外部雕刻、烘焙、动作捕捉资产管线，
也不以“3A”标签替代画面验收。

## 本轮性能对照

Intel Arc / ANGLE D3D11，固定 1280×720、DPR 1，400 个移动近景单位 + 15 建筑，
合成周期性交战、建筑阴影、无泛光、自动 LOD、粒子上限 150。每轮 90 帧预热 + 300 帧采样。
浏览器记录 visibility=visible，双方 artTextureReady=true、detailedUnits=400、lodUnits=0。
与回归脚本并行的一轮基线不纳入下面数据。

| 版本/轮次 | FPS | 帧 p95 / p99 ms | CPU render p50 / p95 ms |
| --- | ---: | --- | --- |
| 第二版 1 | 60 | 16.8 / 16.8 | 3.4 / 4.4 |
| 第二版 2 | 60 | 16.8 / 16.8 | 3.1 / 4.2 |
| 第一版 1 | 60 | 16.8 / 16.8 | 6.0 / 9.7 |
| 第一版 2 | 60 | 16.8 / 16.8 | 6.0 / 7.7 |

两版均 203 次场景绘制调用、6 个关节批次。第二版约 67.8 万三角形，第一版约 66.8 万。
CPU 数字存在明显时段/主机负载差异，不据此宣称渲染速度翻倍；60 Hz 上限也掩盖了 GPU 余量。
结论仅为本次合成渲染场景保持帧率，不能代替完整网络/AI/寻路团战或所有硬件的性能保证。

最终装甲硬表面和细军衔环版本追加 1920×1080（实际渲染缓冲）测试：400 近景单位、15 建筑，
第二版 60 FPS，帧间隔 p95/p99 均 16.8 ms，CPU render p50/p95 为 3.0/4.9 ms；
203 个场景绘制调用，约 67.9 万三角形。浏览器面板虽缩放显示为 1280×720，缓冲为 1920×1080。
同条件第一版为 54.57 FPS，帧 p95/p99 28.8/41.7 ms，CPU p50/p95 3.6/5.2 ms。
这组各一轮的追加数据不作为普遍性能提升结论。
