# 战报 v4：阶段、收支、战损片段（2026-09-17）

## 功能

- 新增“阶段复盘”：每分钟的采集收入、完成造兵 / 建筑目录价、击毁 / 损失价值、交换比、单位 / 建筑 / 矿车损失。
- 同一阶段另表显示真实生产与维修支出、退款 / 出售、奖励 / 补给、时间加权平均持币、持币不少于 5,000 的时长。
- 新增“资金收支”：实际造兵、建造、单位维修、建筑维修扣款，与卸矿、奖励、补给、撤单退款、出售回款分开。调试扣款单列。记录初始和退场 / 终局余额，提供收支核对差额。
- 生产受阻：分别累计造兵、建筑队列、落地施工的缺电等效生产时间损失；建筑队列无建造授权暂停单列。缺电是降速而非停机，不能混称“停电时长”。多队列并行会累加等效秒数。
- 关键战损片段：同一对手的连续敌对击毁，以相邻损失不超过 20 秒聚合；按双方损失原价排序，展示两边损失兵种 / 建筑构成与交换比。
- 以上数据全部支持 CSV 导出，旧版战报继续兼容；更新后新对局才记录 v4 字段。

## 边界与性能约束

阶段以左闭右开区间计数；终局落在边界的事件可能形成零时长尾段。至多 120 段，超长局将相邻段合并为 2、4、8 分钟等，保留数值合计，不截掉旧阶段。资金时长横跨阶段边界时拆分，退场后不再累计。

关键战损片段不等于真实单一地点的战斗：同一对手多线交火可能合并，无击毁的骚扰不会出现，主动自爆和环境损失不归给对手。最多保留 24 个高价值已完成片段，另保留每对玩家一个正在累计的片段；终局统一收束。省略片段数量可见，其战损依然存在于总表和阶段合计中。

不保存逐击或逐笔现金日志，不扩展实时房间快照，不增加游戏渲染帧工作。资金记录挂在现有实际扣款 / 到账点，生产受阻只复用现有生产循环。收支核对差额不为零时不能解释为“经济损失”，而表示未记录资金变动。持有大额现金不自动判定为操作失误。
